# 类说明

卡牌管理关系 StackGroup-->cardStack-->cardRun-->card

move存储每步操作

## Card

存储card ID，以及card名称 和 花色

## cardRun

存储连续的序列，最长为13，包含了检测CardRun间隔，以及加入card方法。

## CardStack

1. 管理一系列的CardRun
2. 加入CardRun的appendRun方法，一般是当前cardRun为null的时候使用。
3. 删除CardRun
4. 移动到空列
5. 

## StackGroup

1. 包含了StackGroup
2. 移动的操作
3. 深度
